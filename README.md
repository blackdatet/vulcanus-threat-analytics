# Vulcanus — анализ Git-репозиториев

Платформа для анализа активности разработчиков в GitHub-репозиториях.

## Цель проекта

Собрать данные о коммитах из GitHub, обработать их, построить профили разработчиков, выявить аномалии в поведении и показать результаты в интерактивном Shiny-дашборде.

## Команда

- Соколов — капитан, архитектура проекта, README, DESCRIPTION, Docker, финальная сборка
- Розинский — ETL, сбор данных из GitHub API
- Хлестков — метрики, аналитика, выявление аномалий
- Рыженин — визуализация, Shiny-дашборд

## Основные возможности

- сбор данных о коммитах;
- очистка и преобразование данных;
- анализ активности разработчиков;
- поиск аномальных коммитов;
- визуализация результатов.

## Технологии

- R
- Shiny
- GitHub API
- Docker
- testthat

## Запуск проекта

### Запуск Shiny-приложения локально

```r
shiny::runApp("app")
```

### Запуск через Docker

```bash
docker build -t vulcanus .
docker run -p 3838:3838 vulcanus
```

### Запуск через Docker Compose

```bash
docker compose up --build
```

После запуска приложение будет доступно по адресу:

```text
http://localhost:3838
```
