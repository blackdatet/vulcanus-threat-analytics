# Vulcanus — анализ Git-репозиториев

Платформа для анализа активности разработчиков в GitHub-репозиториях.

## Цель проекта

Собрать данные о коммитах из GitHub, обработать их, построить профили разработчиков, выявить аномалии в поведении и показать результаты в интерактивном Shiny-дашборде.

## Команда

- Соколов — капитан, архитектура проекта, README, DESCRIPTION, Docker, финальная сборка
- Розинский — ETL, сбор данных из GitHub API
- Хлестков — метрики, аналитика, выявление аномалий
- Рыженин — визуализация, Shiny-дашборд

## Основные возможности

- сбор данных о коммитах;
- очистка и преобразование данных;
- анализ активности разработчиков;
- поиск аномальных коммитов;
- визуализация результатов.

## Технологии

- R
- Shiny

## Запуск проекта

### Запуск Shiny-приложения локально

Для локального запуска через R/Shiny необходимо предварительно установить зависимости:

```r
install.packages(c(
  "shiny",
  "dplyr",
  "ggplot2",
  "lubridate",
  "httr",
  "jsonlite"
))
```

После установки библиотек приложение можно запустить командой:

```r
shiny::runApp("app")
```

### Запуск через Docker

Docker-версия автоматически устанавливает все необходимые зависимости.

```bash
docker build -t vulcanus .
docker run -p 3838:3838 vulcanus
```

### Запуск через Docker Compose

```bash
docker compose up --build
```

После запуска приложение будет доступно по адресу:

```text
http://localhost:3838
```

## Архитектура проекта

Проект состоит из нескольких модулей:

- ETL-модуль:
  загрузка и преобразование данных GitHub API;

- аналитический модуль:
  расчет метрик, профилей разработчиков и поиск аномалий;

- модуль визуализации:
  Shiny-дашборд для отображения аналитики;

- инфраструктурный модуль:
  Docker и docker-compose для запуска проекта.

## Структура проекта

```text
R/           - аналитика и ETL
data/        - пример данных
data-raw/    - генерация и загрузка данных
app/         - Shiny-приложение
tests/       - тесты
vignettes/   - документация
```

## Демонстрационные данные

В проекте используется example_commits.rds —
демонстрационный набор синтетических данных коммитов,
используемый для тестирования аналитики и Shiny-дашборда.
